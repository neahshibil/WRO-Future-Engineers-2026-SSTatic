## 2. Vehicle Overview

Our vehicle is an autonomous robot designed for the WRO Future Engineers 2026 competition.

The vehicle uses an Ackermann-style front steering mechanism and a rear-wheel propulsion system. Its autonomous navigation system combines vision, distance sensing, and heading measurement.

The main sensors used are:

- HuskyLens vision sensor for recognising coloured obstacles
- Time-of-Flight sensors for measuring distance from walls and obstacles
- IMU / gyroscope for measuring vehicle heading and correcting orientation

The robot was developed through repeated mechanical and software testing. Several parts of the chassis, steering system, sensor mounting, and navigation logic were redesigned during development to improve reliability.
